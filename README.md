## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/python-bootcamp.git
cd python-bootcamp
```

### 2. Create a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

On Windows:

```bash
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Start learning

Open the notebooks in Jupyter:

```bash
jupyter notebook
```

You can also use **JupyterLab**, **VS Code**, or **Google Colab**.

## Recommended Learning Approach

1. Follow the lessons in order.
2. Run each example and review its output.
3. Modify the code to test your understanding.
4. Complete the exercises without checking the solution first.
5. Build the mini-projects to apply multiple concepts together.
